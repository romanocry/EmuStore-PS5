Interface précédente conservée avec grille des émulateurs, statuts installés/absents/mise à jour et pictogrammes PS5 × ○ △ □. Version compilée pour environnement homebrew PS5. **Compatibilité réelle non validée sur console.**

### Télécharger et installer

1. Télécharger **EmuStore-PS5-v0.4.0.zip** dans les assets de cette release.
2. Fermer EmuStore sur la console.
3. Extraire le ZIP puis copier le dossier **PPSA97631** entier dans **/data/homebrew/** via FTP. Pour remplacer une ancienne version, remplacer les fichiers de ce seul dossier.
4. Faire redétecter les applications par ShadowMountPlus, puis lancer EmuStore avec l'environnement homebrew habituel.

L'archive contient le binaire, le module système, les ressources et les licences. Aucun jeu, BIOS ou clé fourni.

L'intégrité ZIP et les métadonnées de version ont été vérifiées : identifiant **PPSA97631**, version interne **00.004.000**. Le fichier **SHA256SUMS.txt** contient l'empreinte de l'archive installable.
